Section two. The two kernels.
Both kernels compute the same attention for the same tokens. Each sequence-parallel rank attends its two thousand seventy two query tokens to all four thousand one hundred forty four key and value tokens, for ten heads of one hundred twenty eight dimensions, for each guidance half. They differ only in how that work is mapped onto the Neuron core engines.
The legacy kernel, wan flash self attention, is a hand-written N K I flash attention. It is called once per guidance half, processes heads one after another, pads keys and values from four thousand one hundred forty four to six thousand one hundred forty four tokens, transposes the probability matrix by multiplying it with an identity matrix on the tensor engine, and runs every elementwise step on the vector engine.
The new kernel, attention C T E, comes from the N K I library in the image. It is called once for both guidance halves, uses no padding, computes the exponent on the scalar engine with the max subtraction and the row sum fused in, transposes the probability matrix with D M A, and overlaps one query group's Q K product with an earlier group's P V product.
The math is the same. The new kernel keeps more engines busy at once and wastes less work, so each head takes about point one seven milliseconds instead of about one point three seven.
